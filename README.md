## 🍅 Tomato Price Prediction Using Linear Regression

An **end-to-end data science project** built on real-world agricultural market data.  
This project covers the complete pipeline—from **data scraping and cleaning** to **exploratory data analysis, visualization, and price prediction**—to understand tomato price trends and forecast future movements.

---

### 🚀 What This Project Does

- 📥 Scrapes real-world tomato price data from public sources  
- 🧹 Cleans and preprocesses noisy market data  
- 📊 Performs exploratory data analysis (EDA) and visualization  
- 📈 Applies **Linear Regression** for price prediction  
- 🔍 Analyzes market trends for data-driven insights  

---

### 🧠 Key Highlights

- Built a **price prediction model** using linear regression  
- Used **correlation analysis** for feature selection  
- Visualized trends, relationships, and prediction accuracy  
- Worked with **real agricultural market data**, not synthetic datasets
