End-to-end data science project using real-world tomato price data. 
The project involves data scraping, cleaning, exploratory analysis, visualization, and price prediction using linear regression to understand market trends and future price movement.

*Built a price prediction model using linear regression on real-world agricultural market data, including data scraping, cleaning, visualization, and trend analysis.
